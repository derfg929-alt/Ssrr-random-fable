# Telegram-бот розыгрышей

Бот для проведения розыгрышей в Telegram-каналах: публикует пост с кнопкой
«Участвовать», проверяет подписку, выдаёт билеты за рефералов и бусты,
выбирает победителей и публикует итоги.

## Возможности

- Розыгрыш в канале или группе, где бот администратор.
- Три формата завершения: по времени, по числу участников, по тому, что наступит раньше.
- Капча с картинками при участии (защита от простых скриптов) с лимитом попыток.
- Дополнительные каналы, на которые нужно подписаться.
- Билеты: база + рефералы + бусты канала, с показом шансов участнику.
- Переигровка итогов (в том числе «без прошлых победителей») с историей раундов.
- Экспорт участников в CSV, отчёт владельцу, личные сообщения победителям.
- Напоминания владельцу за 24 часа и за час до конца розыгрыша.
- Русский и английский языки, пост в канале — на языке розыгрыша.
- Резервная копия и восстановление (`/backup`, `/restore`).
- `/mydata` — показать и удалить свои данные.

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export BOT_TOKEN="123456:токен-от-@BotFather"
python main.py
```

Бот работает через long polling, вебхук не нужен. Вместо переменных окружения
можно положить их в файл `.env` рядом с кодом (см. `.env.example`).

1. Добавьте бота администратором в канал с правом «Публикация сообщений».
2. Напишите боту `/start` → «🎉 Создать розыгрыш».
3. Заполните текст, медиа, число победителей и время, затем «🚀 Опубликовать».

## Настройки (переменные окружения)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `BOT_TOKEN` | — | Токен бота, обязателен |
| `DATA_DIR` | `./data` | Каталог данных (на хостинге — постоянный диск) |
| `DB_FILE` | `bot_data.json` | Имя файла снимка данных |
| `ADMIN_IDS` | пусто | ID через запятую: доступ к `/backup`, `/restore` |
| `ADMIN_USERNAME` | пусто | Юзернейм с теми же правами (без `@`) |
| `USERS_ADMIN_ID` | пусто | ID через запятую: кнопки «Статистика» и «Пользователи» |
| `CAPTCHA_ENABLED` | `1` | Капча при участии |
| `REMINDERS_ENABLED` | `1` | Напоминания владельцу о конце розыгрыша |
| `PIN_RESULTS` | `1` | Закреплять итоги в канале |
| `AUTO_DETECT_CHANNELS` | `1` | Запоминать каналы, куда добавлен бот |
| `MAX_LISTED_CHANNELS` | `20` | Сколько каналов показывать в списке |
| `CHANNEL_CACHE_TTL` | `20` | Кэш проверки прав, сек |
| `JOURNAL_COMPACT_OPS` | `500` | Операций журнала до перезаписи снимка |
| `DB_FSYNC` | `1` | Сбрасывать журнал на диск (`0` — быстрее, но риск потери при падении) |
| `LOG_LEVEL` | `INFO` | Уровень логирования |
| `LOG_FILE` | пусто | Писать лог в файл |

Пустые `ADMIN_IDS`/`ADMIN_USERNAME` означают, что команды резервного
копирования недоступны никому — задайте их явно на своём деплое.

## Данные

Данные лежат в `DATA_DIR`:

- `bot_data.json` — снимок;
- `bot_data.json.journal` — журнал последних операций.

Каждая запись дописывается в журнал (O(1)), снимок перезаписывается редко
(при компакции и остановке), поэтому бот не упирается в перезапись файла на
больших объёмах. При старте журнал проигрывается, ничего не теряется.
`/backup` отдаёт актуальный снимок, `/restore` принимает его обратно.

## Тесты

```bash
pip install -r requirements-dev.txt
python -m pytest
```

Тесты не обращаются к Telegram: `tests/fakebot.py` подменяет `TeleBot`,
поэтому прогон занимает пару секунд.

## Структура

| Файл | Ответственность |
|---|---|
| `app.py` | Логирование, создание бота, БД и FSM |
| `main.py` | Команды, меню, мастер создания, кнопки-действия |
| `middleware.py` | Каналы, участие, публикация, итоги, воркер |
| `keyboard.py` | Клавиатуры |
| `tool.py` | Тексты, время, ссылки, HTML |
| `base.py` | Хранилище: снимок + журнал |
| `models.py` | Модели данных |
| `captcha.py` | Генерация капчи и лимиты |
| `config.py` | Настройки из переменных окружения |
| `fsm.py` | Состояния пользователя |

## Приватность

Бот хранит id, имя, юзернейм, язык и участия пользователя. Данные нужны для
проведения розыгрышей и подсчёта билетов. Пользователь может посмотреть их
командой `/mydata` и удалить кнопкой «Удалить мои данные» — участие в
активных розыгрышах и реферальные связи при этом удаляются.
